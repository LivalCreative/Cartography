# Cartography · Tienda

Tienda en línea de Cartography: productos de Estados Unidos entregados en Querétaro.
Sitio estático publicado con GitHub Pages.

- `index.html` — inicio: logo, cómo llega tu pedido, próximos cortes, productos y preguntas frecuentes.
- `producto/?id=...` — página de cada producto: fotos, precio, fechas, descripción y botón para agregar.
- `pedido/` — pantalla final del pedido: resumen, datos y envío del pedido por WhatsApp.
- `assets/productos.js` — catálogo público (solo nombre, fotos, textos y precio final en pesos).
- `assets/tienda.js` — WhatsApp, cuenta para transferencia, fechas de cruce y corte, puntos de entrega y carrito.
- `assets/comun.js` — piezas compartidas: pasos de "Así llega tu pedido", tarjetas de producto y avisos.
- `assets/estilo.css` — estilos de la marca.
- `img/` — logo y fotos de productos.

Lo privado del negocio (precios en dólares, links de compra, fórmula de costos y márgenes) va en Google Drive, carpeta "Tienda Cartography". Este repositorio es público: nunca subir esos datos ni datos de clientas.

Por ahora la página no se muestra en Google (`robots.txt` y `noindex`). Quitar ambos cuando se lance con dominio propio.
